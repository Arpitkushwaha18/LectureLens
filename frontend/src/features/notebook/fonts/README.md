# Notebook math font

STIX Two Math, full OpenType math font, unmodified from STIX release `v2.13b171`.

- Source: https://github.com/stipub/stixfonts/blob/v2.13b171/fonts/static_otf_woff2/STIXTwoMath-Regular.woff2
- SHA-256: `094191335def3f0452c81ec0713cfc2f29bb6af8cecbf79b60881fbf2db97562`
- License: SIL Open Font License 1.1; see `OFL.txt`.

The full font is needed for native MathML radicals/stretchy symbols. Latin-only
webfont subsets omit these glyphs. It is served locally by Vite and embedded in
PDF exports; rendering never downloads fonts from a third-party service.
